# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. All contributors and maintainers are expected to follow it in every project space: issues,
pull requests, discussions and any community channel.

## Our standards

Be respectful and constructive. Assume good intent, critique ideas rather than people, and welcome newcomers.
Harassment, personal attacks, discriminatory language and publishing others' private information are not tolerated.

## Enforcement

Report unacceptable behaviour privately to the maintainers via
[GitHub private reporting](https://docs.github.com/en/communities/moderating-comments-and-conversations/reporting-abuse-or-spam)
or the contact listed on the maintainer's GitHub profile. Reports are reviewed promptly and handled confidentially.
Maintainers may remove, edit or reject contributions, and temporarily or permanently ban contributors, following the
Contributor Covenant's enforcement guidelines.
